# Nubank acadêmico — conectar e usar

Banco digital de demonstração com React, Supabase e Capacitor.

**A configuração agora é pela tela: execute o SQL, cole URL e chave pública e entre. Não exige .env.**

- **PRONTO-PARA-PUBLICAR/**: site compilado para GitHub → Vercel, sem instalar dependências.
- **supabase/01-banco.sql**: instalação e atualização do banco.
- **COMECE-AQUI.md**: passo a passo completo.
- **src/**: código-fonte.
- **android/**: projeto nativo.

Para todos os visitantes usarem o mesmo banco automaticamente, preencha ou baixe o config.json pela tela e publique-o junto com o site.

Para desenvolvimento:

```bash
npm ci
npm run dev
```

Para gerar a versão pronta:

```bash
npm run build
```

Valores fictícios, projeto acadêmico independente, sem vínculo com a instituição Nubank.
